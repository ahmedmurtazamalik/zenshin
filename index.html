Connect to Codex

One-time setup

Give your Codex the tools to request one Chrome password selection or terms checkbox action and receive the result in the same turn.

  1. Install the Codex CLI, sign in with codex login, and keep Zenshin running. Chrome actions require Windows; chat monitoring also works on Linux.
  2. Connect once using the button below. This registers Zenshin tools and adds guidance to your Codex instructions so new chats know when to use them. Other tools and approval settings stay unchanged.
  3. Reload MCP connections or restart Codex once. Enable your actions, select any chats that should receive automatic setup, then Start monitoring. Zenshin sends each selected chat its setup prompt when idle and updates it when your enabled Chrome actions change.

Check connection to verify chat access and tool registration separately.

Individual Chrome actions
Windows

        
        
        
        
Codex requests the action through the connected Zenshin tools; Zenshin performs it in Chrome and returns confirmation. Zenshin identifies password fields and agreement boxes from their meaning and nearby text. It opens and selects Chrome's native password suggestion; Chrome generates and fills the password. An exact checkbox label is not required.

        
CAPTCHA solving uses your signed-in Codex CLI to interpret the visible challenge and verify the result. It uses your Codex account's model usage; no external CAPTCHA solver service is needed. Unsupported challenges or unconfirmed results are logged as failures.

        
The connected tools tell Codex to use Zenshin automatically for these actions. While monitoring, each selected chat also receives one setup prompt and an update whenever these saved switches change. Zenshin waits for an idle chat with an empty draft. Codex supplies the current page URL with each request; Chrome must already show the intended page.

        
Choose the actions you authorize, then select Start monitoring. Actions run immediately and are logged in Activity. Pause disables Chrome actions and chat monitoring. Saving settings also pauses them. Terms bundled with marketing consent are allowed; separate marketing boxes are left alone. No account is submitted.
