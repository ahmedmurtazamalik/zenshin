ZENSHIN - WINDOWS SETUP

Zenshin includes Python and its Windows accessibility dependencies.
Install and sign in to Codex desktop and the Codex CLI before use.
Chrome is required for Chrome password and terms actions.

Launch Zenshin from the Start menu. Its controls open in a dedicated desktop
window. Close the window to stop the app. There is no browser tab or console.
Choose Connect Zenshin tools, then reload MCP connections or restart Codex.
Connect also installs reusable Codex guidance for new chats; there is no
per-chat prompt. Choose or edit the AI instructions, enable Chrome actions
and/or select chats, save, then Start monitoring. Saved choices are preserved
on upgrade. There is no Preview mode or exact-question matching.
Keep the desktop window open while monitoring chats.

Setup checks for Microsoft WebView2 Runtime and installs it if missing.
Internet access is needed for that step. Portable ZIP users must install
WebView2 Runtime first and keep Zenshin-bridge.exe beside Zenshin.exe.

UPDATES
In Connect to Codex, choose Check for updates, then Install update.
Zenshin downloads and verifies the installer, pauses monitoring, upgrades
in place, reopens, and replaces its old Codex tool registration automatically.
Codex may need an MCP reload or restart to load the updated bridge.
No uninstall or terminal commands are needed. To upgrade from an older
release without this button, close Zenshin and run the new installer once.
Launch Zenshin from the installer to repair its registration.
Settings and the permanent attempt journal are stored in .local\state.json
inside the installation folder. The installer preserves them on upgrades;
uninstall also leaves them in place. Keep this file private.

To move from a portable/source installation, stop the old app and copy its
.local folder into the new installation folder before launching. Never run
both installations together. Choose Connect Zenshin tools in the new app to replace the old
tool registration automatically.

Uninstall through Windows Settings > Apps. To remove the Codex tool
registration as well, run codex mcp remove zenshin. Back up .local before
manually deleting it; deleting the journal can permit duplicate actions.

This unsigned app may display a Windows publisher warning. The installer
does not install Codex, sign you in, or enable Chrome actions automatically.
Start enables selected Chrome actions and chat replies. Pause or Save blocks
further actions. Activity records results automatically without a review queue. Native actions require your normal, unlocked Windows desktop session.
